what this is

A small pipeline that turns public market data into a spreadsheet and a dashboard, without anyone touching either by hand.

overview

The scraper checks a set of market sources on a fixed schedule, pulls price, volume and change data for a watchlist of tickers, and lands it in a SQL database. From there, Excel workbooks and Power BI reports read straight from the warehouse, so the desk always opens a report built on the same numbers the scraper just collected.

pipeline

  • Extraction — Python requests the source pages on a schedule and parses out ticker, price, change and volume.
  • Storage — Cleaned rows are written to a SQL database, keyed by ticker and timestamp, with older snapshots kept for trend queries.
  • Spreadsheets — Excel workbooks connect directly to the database, so formulas and pivot tables refresh without a manual export.
  • Reporting — Power BI reads the same tables to build the charts the desk checks each morning.

why it's built this way

Keeping one source of truth in SQL means the Excel and Power BI layers never drift apart — a number on the spreadsheet always matches the chart in the report, because both are reading the same table the scraper just wrote to.
